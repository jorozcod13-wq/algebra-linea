Aplicación de las matrices en el procesamiento de imágenes digitales

Descubre cómo las matrices permiten representar, almacenar y transformar imágenes mediante operaciones matemáticas.

1. ¿Cómo se utilizan las matrices en las imágenes digitales?

En Ingeniería en Sistemas, las matrices permiten representar, almacenar y modificar imágenes digitales. Una imagen está formada por pequeños puntos llamados píxeles, que se organizan en filas y columnas.

Gracias a las matrices, un programa puede aumentar o disminuir el brillo, ajustar el contraste, aplicar filtros, detectar bordes y preparar imágenes para sistemas de reconocimiento.

Ejemplo: al aumentar el brillo de una fotografía desde un teléfono, el software puede modificar numéricamente la intensidad de sus píxeles.

2. Imagen en escala de grises como matriz

En una imagen en escala de grises de 8 bits, cada píxel tiene un valor entre 0 y 255. El 0 representa negro, el 255 blanco y los valores intermedios diferentes grises.

0 · Negro
128 · Gris
255 · Blanco

Ejemplo: una imagen de 3 filas y 3 columnas puede representarse con esta matriz:

A = [ [50, 100, 150], [80, 120, 180], [30, 90, 200] ]

3. Problema práctico: aumentar el brillo

Problema: un estudiante desarrolla un programa para editar fotografías y necesita aclarar una imagen oscura. Para ello, aumentará 40 unidades la intensidad de cada píxel de la matriz original.

Paso 1. Matriz original

⎡ 50 100 150 ⎤
⎢ 80 120 180 ⎥
⎣ 30 90 200 ⎦

Paso 2. Operación

B[i,j] = min(255, A[i,j] + 40)

Se suma 40 a cada elemento. La función min(255, ...) impide superar el máximo permitido para píxeles de 8 bits.

⎡ 50+40 100+40 150+40 ⎤
⎢ 80+40 120+40 180+40 ⎥
⎣ 30+40 90+40 200+40 ⎦

Paso 3. Matriz resultante

⎡ 90 140 190 ⎤
⎢ 120 160 220 ⎥
⎣ 70 130 240 ⎦

Resultado: todos los píxeles son más claros. Ninguno supera 255 en este ejemplo.

5. Utilidad en Ingeniería en Sistemas y limitaciones

¿Para qué sirve?

  • Edición de fotografías: permite aclarar imágenes oscuras.
  • Seguridad: facilita la visualización de grabaciones con poca luz, si existen detalles capturados.
  • Imágenes médicas: permite ajustar la visualización, sin crear información nueva.
  • Visión artificial: puede formar parte del preprocesamiento de imágenes.

Limitaciones

  • Saturación: los valores que superarían 255 se limitan a 255 y se pierden diferencias entre píxeles claros.
  • Ruido: aclarar una imagen también puede hacer más visibles sus imperfecciones.
  • Información perdida: aumentar el brillo no recupera detalles que la cámara nunca captó.
  • Calidad: sumar una constante no mejora por sí solo el contraste ni corrige todas las condiciones de iluminación.
Ejemplo del límite: si un píxel vale 230 y sumamos 40, obtenemos 270. Como el máximo es 255, el programa guarda 255.
